# Plugin Dewa 🔱

**Pabrik website all-in-one untuk Claude Code.** Satu input: nama website. Sisanya keputusan yang kamu acc satu per satu — lalu Dewa membangun website company-grade dan merawatnya seumur hidup proyek.

## Instalasi

Di dalam Claude Code, jalankan:

```
/plugin marketplace add Kstriabintang/plugin-dewa
/plugin install dewa@plugin-dewa
```

Lalu mulai:

```
/dewa:buat NamaWebsiteKamu
```

### English

**Dewa** ("deity" in Indonesian) is an all-in-one website factory plugin for Claude Code: give it one website name, approve a series of curated decisions one by one (purpose, industry, colors, typography, UI style, motion, content), and it builds a company-grade website from the resulting brief — then keeps maintaining it (revise, rebrand, audit, deploy). Currently at an early milestone (v0.1.0); the wizard is Indonesian-first, with bilingual support planned. Install with the commands above.
